Complete HTML documentation designed to guide any AI or developer to reproduce the same Laravel storefront, admin panel, and content-driven homepage.

1. Purpose

This document serves as the definitive site reproduction specification for the Steve Auto Parts application. It includes the stack, routes, database schema, admin data model, behavior, and implementation details required to rebuild the website in Laravel.

4. Project structure

The codebase follows Laravel conventions with extension points for storefront and admin features.

  • app/: Models, Controllers, Traits, helpers.
  • resources/views/: Blade templates for public and admin UIs.
  • routes/web.php: all HTTP route definitions.
  • database/migrations/: schema migrations for tables and relationships.
  • database/seeders/: seeders for default data.
  • public/: web root, uploaded media, built assets.
  • storage/: logs, cache, application files.

The home page sections controller validates fields, uploads images, handles external image selection, and stores extra content in JSON.

        $section = HomePageSection::findOrFail($id);

        $validated = $request->validate([
            'title' => 'nullable|string|max:255',
            'subtitle' => 'nullable|string|max:255',
            'description' => 'nullable|string',
            'button_text' => 'nullable|string|max:100',
            'button_url' => 'nullable|string|max:255',
            'status' => 'nullable|boolean',
            'image' => 'nullable|image|mimes:jpeg,png,jpg,gif,webp|max:5120',
            'tabs' => 'nullable|array',
            'tabs.*.label' => 'nullable|string|max:255',
            'tabs.*.product_ids' => 'nullable|array',
            'tabs.*.product_ids.*' => 'integer|exists:products,id',
        ]);

        if ($request->hasFile('image')) {
            $validated['image'] = saveImageWithWebp($request->file('image'), 'assets/images/home');
        } elseif ($request->filled('image_from_manager')) {
            $sourcePath = storage_path('app/public/' . $request->image_from_manager);
            if (file_exists($sourcePath)) {
                $filename = time() . '_' . uniqid() . '.' . pathinfo($request->image_from_manager, PATHINFO_EXTENSION);
                $destDir = public_path('assets/images/home');
                if (!is_dir($destDir)) mkdir($destDir, 0755, true);
                copy($sourcePath, $destDir . '/' . $filename);
                $validated['image'] = $filename;
            }
        }

        if ($request->has('tabs')) {
            $tabs = $request->input('tabs');
            // Clean up empty tabs
            $tabs = array_values(array_filter($tabs, fn($t) => !empty(trim($t['label'] ?? ''))));
            $validated['extra_data'] = ['tabs' => $tabs];
        }

        $existing = $section->extra_data ?? [];

        if ($request->filled('brands_limit')) {
            $existing['brands_limit'] = $request->brands_limit;
        }

        if ($request->has('brand_ids')) {
            $existing['brand_ids'] = array_values(array_filter(array_map('intval', (array) $request->input('brand_ids', []))));
        }

        if ($request->filled('brands_limit') || $request->has('brand_ids')) {
            $validated['extra_data'] = $existing;
        }

        $section->update($validated);

        return redirect()->route('admin.home-page.index')
            ->with('success', 'Section updated successfully!');
    }

6.2 Public home page behavior

HomeController assembles page data with categories, active sections, featured products, explore tabs, best selling products, latest posts, and selected brands.

        $brandsSection = $sections->get('top_brands_heading');
        $brandsExtra = $brandsSection?->extra_data ?? [];
        $selectedBrandIds = $brandsExtra['brand_ids'] ?? [];
        $brandsLimit = $brandsExtra['brands_limit'] ?? '6';
        $brandsLimit = $brandsLimit === 'all' || $brandsLimit === '' ? '6' : $brandsLimit;

        $brandsQuery = Brand::where('status', true)
            ->orderBy('name');

        if (!empty($selectedBrandIds) && is_array($selectedBrandIds)) {
            $selectedBrandIds = array_filter(array_map('intval', $selectedBrandIds));
            if (!empty($selectedBrandIds)) {
                $brandsQuery = Brand::whereIn('id', $selectedBrandIds)
                    ->where('status', true)
                    ->orderByRaw('FIELD(id, ' . implode(',', $selectedBrandIds) . ')');
            }
        } elseif ((int) $brandsLimit > 0) {
            $brandsQuery->take((int) $brandsLimit);
        }

        $brands = $brandsQuery->get();

        return view('home', compact('categories', 'featuredProducts', 'exploreTabs', 'heroSection', 'bannerSections', 'bestSelling', 'sections', 'latestPosts', 'brands'));

7. Features and behavior

Public storefront

  • Homepage section-driven hero, banners, explore tabs, featured products, top brands, and blog teasers.
  • Shop listing, category navigation, product detail pages, search suggestions.
  • Product review creation, editing, and deletion.
  • Contact seller form on product pages.
  • Static pages and content pages via the CMS.

Cart and checkout

  • Shopping cart management with add/remove/update.
  • Authenticated checkout with delivery info and payment steps.
  • Address CRUD and default selection.
  • Order confirmation page.

Customer account

  • User dashboard, orders, reviews, wishlist, vehicles, followed sellers, addresses, notifications, profile management.

Admin panel

  • Separate admin login and dashboard.
  • Product import/export and status controls.
  • Brand, blog, page, FAQ, coupon management.
  • Homepage CMS with section reorder and dynamic tabs.
  • Header/footer settings, logs, revisions, file revisions, image manager.

8. Administrative data management

The admin panel includes these management domains and exact operations:

  • Products: list, create, edit, delete, restore, force delete, import CSV, export CSV, toggle status, toggle featured.
  • Categories: list, create, edit, restore, force delete, toggle status.
  • Brands: list, create, edit, delete, toggle status.
  • Blogs: list, create, edit, delete, restore, force delete, toggle status.
  • Pages: CMS pages with activation toggles.
  • FAQs: FAQ list and publish control.
  • Coupons: promotional coupon CRUD.
  • Contacts: support messages list and delete.
  • Images: upload, picker, edit, convert, bulk actions.
  • Users and staff: create, edit, delete, toggle status, role-limited access.
  • Home page sections: manage hero, banners, product tabs, brand configuration, ordering.

10. Reproduction guidance for AI

This HTML is intentionally written as a reproducible specification. An AI should use the following checklist to rebuild the same Laravel application:

  1. Begin with a Laravel 13 application and PHP 8.3.
  2. Implement the route groups and controller actions described above.
  3. Create the database tables and columns based on section 6, especially home_page_sections, products, categories, users, orders, order_items, and addresses.
  4. Recreate the homepage composition logic: hero and banner sections, explore tabs, featured/best-selling products, latest blog posts, and top brands configuration.
  5. Implement admin role control with auth, nocache, and role middleware.
  6. Use the homepage CMS and image upload validation rules exactly as shown.
  7. Rebuild the customer dashboard and checkout flows with authenticated routes and address management.
  8. Preserve the dependency and build tool versions from composer.json and package.json.

Following this specification will allow any AI-enabled tool or human developer to reproduce the original website behavior and admin content management features.
