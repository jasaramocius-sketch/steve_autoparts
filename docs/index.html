Getting Started

Requirements:

  • PHP 8.3+
  • Composer
  • Node.js 18+ and npm
  • Git
  • MySQL/MariaDB or SQLite

Typical local setup:

composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --force
npm install
npm run dev

Development Guide

Common developer commands:

composer run dev
vendor/bin/pint
composer test

The main folders are:

  • app/ — application code
  • resources/views/ — Blade templates
  • resources/js/ and resources/css/ — frontend assets
  • routes/web.php — public and admin routes
  • database/ — migrations and seeders

Deployment Guide

Production deployment checklist:

  • Install PHP, Composer, Node, and required extensions
  • Configure .env with production values
  • Run migrations and build frontend assets
  • Cache config and routes
  • Configure queue workers and web server
composer install --no-dev --optimize-autoloader
npm ci
npm run build
php artisan migrate --force
php artisan config:cache

Architecture Overview

The project is a Laravel 13 application with server-rendered Blade templates and Vite-powered frontend assets. Public routes and admin routes are both defined in routes/web.php.

  • HTTP layer: controllers and routes
  • Data layer: Eloquent models and migrations
  • Presentation layer: Blade views and Vite assets
  • Admin panel: role-based access for admin and staff users

Database

The default setup uses SQLite in .env.example, while production should use MySQL/MariaDB. Schema changes are managed with Laravel migrations and seeders.

php artisan migrate --force
php artisan db:seed

Useful assets:

  • stautoparts.sql — SQL snapshot
  • sample-products-import.csv — sample import file

Testing

Run automated tests with PHPUnit:

composer test

Useful variants:

vendor/bin/phpunit
vendor/bin/phpunit tests/Feature/ExampleTest.php

Operations & Maintenance

Key operational tasks include file uploads, backups, monitoring, maintenance mode, and queue worker health.

  • Upload images under public/assets/images/
  • Review backup utilities in backup/ and copy_backup.py
  • Monitor logs under storage/logs/
  • Use maintenance mode during upgrades

Contributing

To contribute:

  1. Create a feature or fix branch
  2. Implement the change and run tests
  3. Open a pull request with a description and testing details

FAQ & Troubleshooting

  • If homepage content is not updating, verify active home page sections and migrations.
  • If images fail to upload, check permissions and allowed file formats.
  • If product import fails, confirm the CSV format and server upload limits.
  • If queues fail, confirm a queue worker is running.
